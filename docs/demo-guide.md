# 시연 가이드 (1R 심사 촬영용)

## 준비

1. `./scripts/run_local.sh` 로 서버 실행
2. 노트북 브라우저에서 `http://localhost:8000/` 접속 → 개발자도구에서 모바일 뷰(예: iPhone 14, 390×844)로 전환하거나, 휴대폰에서 `http://<PC IP>:8000/`
3. 화면 녹화 시작 (휴대폰 화면 녹화 또는 OBS)

## 촬영 팁

- 알림 모달은 **분석 테스트 실행 후 자동으로** 뜹니다(미확인 알림 존재 시). 닫았다면 홈의 "확인하지 않은 알림" 카드로 다시 엽니다.
- `낙상 테스트`(상단 버튼)는 카메라 없이 알림 흐름만 확인할 때 사용합니다. `is_test` 표시가 붙습니다.
- 시나리오를 연속 실행하면 같은 날짜 리포트가 **upsert**되어 마지막 시나리오 점수로 갱신됩니다. 초기 상태로 돌리려면 `데모 초기화`.
- 서버가 꺼져 있으면 앱은 데모 데이터로 폴백하고 상단 배지가 `데모`로 바뀝니다. (네트워크 장애 시연에 활용 가능)

## 자주 쓰는 명령

```bash
# 서버만 다시 띄우기
cd api-server && uvicorn app.main:app --host 0.0.0.0 --port 8000

# 데이터 초기화 + 재시드
cd api-server && python scripts/dev_bootstrap.py --reset --skip-migrate

# 파이프라인 단독 확인
cd camera-analysis && python -m onview.cli analyze --scenario fall

# 실제 HTTP 전송 + DB 저장까지 자동 검증
python scripts/e2e_demo.py
```

## 문제 해결

| 증상 | 확인 |
|---|---|
| 로그인 401 | `python scripts/dev_bootstrap.py --skip-migrate` 로 데모 계정 재생성 |
| 화면이 데모로 표시 | 서버 실행 여부·포트, 브라우저 콘솔의 fetch 오류 |
| 휴대폰에서 안 열림 | 같은 Wi-Fi인지, PC 방화벽에서 8000 포트 허용, `--host 0.0.0.0` |
| 분석 테스트가 실패 | 서버 로그 확인. `/api/v1/demo/config` 가 `enabled:true` 인지 |
| MediaPipe 미동작 | `python -m onview.cli mediapipe-check --image 사진.jpg` 로 백엔드/모델 확인 |
