보호자에게 따뜻한 말로 하루를 전합니다.

  • 02 매일 아침 안심 점수와 리포트
  • 03 앱에서 어르신 정보 수정

보호자 로그인

시연용 데모 계정으로 로그인됩니다.

오늘의 안심 리포트

-
SOS 안심전화

홈온큐는 의료 진단을 대신하지 않습니다. 리포트는 관절 좌표 분석 기반 참고 자료입니다.

최근 이벤트

자세·동작 분석 테스트

샘플 관절좌표를 실제 분석 파이프라인으로 처리한 뒤, 기기용 텔레메트리 API로 전송하고 DB에 저장합니다. 끝나면 리포트와 알림이 바로 갱신됩니다.

시연 흐름
  1. 샘플 관절좌표(33관절 시퀀스) 로드
  2. 규칙 기반 낙상·무활동·배회 감지
  3. POST /api/v1/device/* 전송 → SQLite 저장
  4. 보호자 리포트·낙상 알림 화면 갱신
